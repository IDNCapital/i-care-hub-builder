## Mission 2 (S, priorité 2) · centraliser `norm()` — ARRÊTÉE, PRÉMISSE RÉFUTÉE

**Aucun commit. Aucun fichier touché.**

La mission demande de centraliser « le helper `norm()` **dupliqué** entre
`scripts/publishedRoutes.mjs` et `src/lib/taxonomy.ts` en un module unique
importable des deux côtés, **sans changer son comportement** ».

**Les deux implémentations ne sont pas la même fonction.**

```
$ sed -n '14,19p' src/lib/taxonomy.ts
export const norm = (s: string) =>
  s
    .toLowerCase()
    .normalize("NFD")
    .replace(/[̀-ͯ]/g, "");

$ sed -n '14,20p' scripts/publishedRoutes.mjs
export function norm(s) {
  return String(s ?? "")
    .toLowerCase()
    .normalize("NFD")
    .replace(/[̀-ͯ]/g, "");
}
```

`String(s ?? "")` n'est pas une coquetterie : c'est un **contrat différent**.
Différences mesurées, les deux corps joués côte à côte sur les mêmes entrées :

| entrée | `taxonomy.ts` | `publishedRoutes.mjs` |
|---|---|---|
| `null` | **TypeError** : Cannot read properties of null | `""` |
| `undefined` | **TypeError** : Cannot read properties of undefined | `""` |
| `42` | **TypeError** : s.toLowerCase is not a function | `"42"` |
| `{}` | **TypeError** | `"[object object]"` |
| `["Éa"]` | **TypeError** | `"ea"` |
| `"Épée"`, `"ÀÉÎÕÜ"`, `""`, `"deja"` | identiques | identiques |

Sur toute chaîne, les deux rendent le même résultat. Sur `null`, `undefined` et
tout non-chaîne, l'une **lève** et l'autre rend une valeur.

**Pourquoi c'est bloquant, et pas une chicane.** La différence est atteignable
sur des données réelles. `matchSpecialite` et `matchProblematique` appliquent
`norm` à des tableaux venus de la base, sans garde :

```
$ grep -n 'norm(' src/lib/taxonomy.ts
339:  return candidates.some((c) => targets.includes(norm(c)));
385:    targets.includes(norm(tag)),
400:    const key = norm(tag);
```

```
   332:  const targets = [specialite.nom, ...(specialite.synonymes ?? [])].map(norm);
   …
   339:  return candidates.some((c) => targets.includes(norm(c)));
```

`specialite.nom` et les éléments de `synonymes` ou de `specialites` viennent de
Supabase et peuvent être `null`. **Aujourd'hui, un `null` dans ces tableaux fait
lever `matchSpecialite`. Avec le corps tolérant, il rendrait `""` et ne
correspondrait silencieusement à rien.** Un appariement qui échoue bruyamment
deviendrait un appariement qui échoue en silence — sur la taxonomie qui décide
quelles pages praticien sont prérendues. La ligne 400, elle, est gardée par
`if (!tag) continue;` : la différence n'y est pas atteignable, ce qui montre bien
que la garde a été posée là exprès et pas ailleurs.

Centraliser impose donc de **choisir** lequel des deux contrats devient le
contrat unique. C'est précisément ce que la mission interdit (« sans changer son
comportement ») et ce que la charte réserve au jour. La mission s'arrête ici, et
ne se contourne pas.

**Ce qui est prêt pour le jour, si la décision tombe.** Un module `src/lib/` en
JavaScript nu, importable tel quel par `scripts/publishedRoutes.mjs` (qui se
déclare « zero external dependency ») et par `src/lib/taxonomy.ts` via Vite —
`tsconfig` porte déjà `allowJs: true` et `noImplicitAny: false`. Le sens inverse
(module sous `scripts/`) ferait entrer du code d'outillage dans le bundle client
et est à écarter. Le précédent d'une compilation TypeScript à la volée existe
dans le dépôt (`checkRoutesConcordance.mjs` transforme `src/lib/routes.ts` par
esbuild), mais l'employer ici ajouterait `esbuild` aux dépendances du sitemap et
du prérendu et détruirait la propriété « zéro dépendance » de
`publishedRoutes.mjs` : à écarter aussi.

**Hors périmètre, mais relevé au passage** : un troisième `norm` existe dans
`scripts/checkRoutesConcordance.mjs` (ligne 51). Il normalise des **chemins
d'URL**, pas des libellés — homonyme, fonction sans rapport. Il ne doit surtout
pas être versé dans la centralisation. Un quatrième miroir de la taxonomie vit
dans `supabase/functions/_shared/taxonomy.ts`, que l'en-tête de `taxonomy.ts`
demande de propager à la main ; il est hors du périmètre nommé par la mission.

**Rollback** : sans objet, rien n'a été fait.
